# Анализ аудитории

## 0. Перед началом

1. Прочитай `~/.claude/brand/PROFILE.md` — кто Софья, её метод, история, продукты, аудитория, границы. Без этого не работай.
2. Прочитай `~/.claude/brand/TOV-SAMPLES.md` — её живые тексты, эталон голоса. Если файл почти пуст — пиши нейтрально-тепло и попроси Софья прислать 10–15 её текстов.
3. Прочитай `~/.claude/brand/WRITING-RULES.md` — правила живой речи. Они обязательны для каждого текста.
4. Ничего не выдумывай: ни фактов, ни цифр, ни кейсов, ни регалий. Нет детали — ставь `[нужна деталь: какая]` прямо в тексте и задай Софья один точный вопрос после ответа.
5. Готовый текст отдавай без вступлений «вот твой текст» и без разбора после — разбор только по просьбе.

## Задача

Собрать рабочий портрет аудитории Софья, на который опираются офферы, прогревы и контент. Основа — реальный материал: кастдевы, отзывы, переписки, кейсы из PROFILE.md. Если материала мало — так и скажи и дай список из 8–10 вопросов для кастдева, а не выдумывай портрет из головы.

## Что на выходе

1. Один главный аватар (не три сегмента): кто она, день из её жизни, что уже пробовала.
2. Боли — дословными фразами клиентов, три уровня: симптом (что болит), следствие (что отнимает), глубина (чего лишает в жизни: отношения, деньги, свобода).
3. Возражения и чем снимается каждое (факт, кейс, гарантия, формат).
4. Триггеры покупки: что реально двигает к оплате.
5. Язык аудитории: слова и фразы, которые переиспользовать в текстах.

## Правила

Каждый тезис помечай источником: «из кастдева», «из отзыва», «гипотеза — проверить». Гипотезы отдельно от фактов.
