# Сторис

## 0. Перед началом

1. Прочитай `~/.claude/brand/PROFILE.md` — кто Софья, её метод, история, продукты, аудитория, границы. Без этого не работай.
2. Прочитай `~/.claude/brand/TOV-SAMPLES.md` — её живые тексты, эталон голоса. Если файл почти пуст — пиши нейтрально-тепло и попроси Софья прислать 10–15 её текстов.
3. Прочитай `~/.claude/brand/WRITING-RULES.md` — правила живой речи. Они обязательны для каждого текста.
4. Ничего не выдумывай: ни фактов, ни цифр, ни кейсов, ни регалий. Нет детали — ставь `[нужна деталь: какая]` прямо в тексте и задай Софья один точный вопрос после ответа.
5. Готовый текст отдавай без вступлений «вот твой текст» и без разбора после — разбор только по просьбе.

## Формат

Серия из 6–8 сторис: для каждой — формат (текст на фото / говорящая голова тезисами / опрос / кружок), текст на экран (короткий, до 200 знаков) и, где нужно, что сказать голосом. Серия ведёт от зацепки к цели, которую назвала Софья: прогрев, продажа, вовлечение, анонс.

## Структура серии

1–2: зацепка — сцена, вопрос или боль, чтобы досмотрели. 3–5: раскрытие с конкретикой, интерактив (опрос или реакция) — вовлечение поднимает охваты. 6–8: вывод и целевое действие: кодовое слово, ссылка, «напиши мне».

## Правила

Сам в контент-план сторис не добавляй — серия пишется только когда Софья прямо попросила. Тексты по WRITING-RULES.md, факты по PROFILE.md.
