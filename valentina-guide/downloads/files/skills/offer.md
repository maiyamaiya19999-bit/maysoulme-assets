# Оффер и лендинг

## 0. Перед началом

1. Прочитай `~/.claude/brand/PROFILE.md` — кто Валентина, её метод, история, продукты, аудитория, границы. Без этого не работай.
2. Прочитай `~/.claude/brand/TOV-SAMPLES.md` — её живые тексты, эталон голоса. Если файл почти пуст — пиши нейтрально-тепло и попроси Валентина прислать 10–15 её текстов.
3. Прочитай `~/.claude/brand/WRITING-RULES.md` — правила живой речи. Они обязательны для каждого текста.
4. Ничего не выдумывай: ни фактов, ни цифр, ни кейсов, ни регалий. Нет детали — ставь `[нужна деталь: какая]` прямо в тексте и задай Валентина один точный вопрос после ответа.
5. Готовый текст отдавай без вступлений «вот твой текст» и без разбора после — разбор только по просьбе.

## Формула оффера

«[Продукт], на котором ты получишь [конечный результат] за [срок] — без [возражение 1] — без [возражение 2] — даже если [страх]». Результат — конкретный и представимый (цифра, срок, картинка жизни), из большой тройки желаний: деньги, отношения, здоровье и красота. «Энергию», «осознанность» и «трансформацию» не продаём — их не покупают; они идут вторым слоем как последствие результата.

Оффер всегда из плюса: читательница достойна лучшего и уже способна, ей не хватает системы. Никаких заходов через «с тобой что-то не так».

## Как работаешь

1. Собери из PROFILE.md: продукт, результат, кейсы, боли аудитории, возражения. Чего нет — спроси.
2. Дай 3–4 варианта оффера одним коротким абзацем каждый: большое обещание + снятие возражений через тире. Валентина выбирает.
3. После выбора — полный текст лендинга по секциям: hero (оффер + «без …» + обещание первого результата), «для тебя, если» (6–7 пунктов узнавания), «почему получится, даже если раньше не получалось», программа по модулям через результат, «что ты получаешь», результаты по времени, честный блок «кому не подойдёт», цена (стартовая + перечёркнутая полная + «дальше только выше»).

## Правила

Тексты по WRITING-RULES.md. Цены и обещания только реальные — за медицинские и денежные гарантии отвечает Валентина, сомнительное помечай `[проверь: …]`.
