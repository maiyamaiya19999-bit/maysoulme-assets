# Прогрев

## 0. Перед началом

1. Прочитай `~/.claude/brand/PROFILE.md` — кто Валентина, её метод, история, продукты, аудитория, границы. Без этого не работай.
2. Прочитай `~/.claude/brand/TOV-SAMPLES.md` — её живые тексты, эталон голоса. Если файл почти пуст — пиши нейтрально-тепло и попроси Валентина прислать 10–15 её текстов.
3. Прочитай `~/.claude/brand/WRITING-RULES.md` — правила живой речи. Они обязательны для каждого текста.
4. Ничего не выдумывай: ни фактов, ни цифр, ни кейсов, ни регалий. Нет детали — ставь `[нужна деталь: какая]` прямо в тексте и задай Валентина один точный вопрос после ответа.
5. Готовый текст отдавай без вступлений «вот твой текст» и без разбора после — разбор только по просьбе.

## Задача

План прогрева на 7–14 дней к продукту Валентина (какому — спроси, если не сказано; варианты в PROFILE.md, раздел «Продукты»). Для каждого дня: платформа и формат (reels / пост / сторис), смысловая нить и готовый черновик текста или сценария.

## Смысловые нити (в этом порядке, с перекрытием)

1. Боль и узнавание — аудитория видит себя.
2. Причина — почему у неё до сих пор не получилось (не её вина).
3. Метод — как это решается по системе Валентина, без раскрытия всего.
4. Доказательства — кейсы и история Валентина (только реальные из PROFILE.md; кейсов нет — линию строим на её личном пути и опыте, а не на выдумках).
5. Продукт — что внутри, для кого, что изменится.
6. Открытие продаж — оффер, цена, дедлайн, снятие возражений.

## Правила

Каждый черновик — по WRITING-RULES.md и под голос из TOV-SAMPLES.md. Дедлайны и цены — только реальные, из PROFILE.md или от Валентина. Прогрев не должен ощущаться прогревом: каждая единица самоценна, её интересно смотреть, даже если не купишь.
