# Посты для Telegram

## 0. Перед началом

1. Прочитай `~/.claude/brand/PROFILE.md` — кто Валентина, её метод, история, продукты, аудитория, границы. Без этого не работай.
2. Прочитай `~/.claude/brand/TOV-SAMPLES.md` — её живые тексты, эталон голоса. Если файл почти пуст — пиши нейтрально-тепло и попроси Валентина прислать 10–15 её текстов.
3. Прочитай `~/.claude/brand/WRITING-RULES.md` — правила живой речи. Они обязательны для каждого текста.
4. Ничего не выдумывай: ни фактов, ни цифр, ни кейсов, ни регалий. Нет детали — ставь `[нужна деталь: какая]` прямо в тексте и задай Валентина один точный вопрос после ответа.
5. Готовый текст отдавай без вступлений «вот твой текст» и без разбора после — разбор только по просьбе.

## Типы постов

- **Личный** — сцена из жизни Валентина → наблюдение, которое разворачивает сцену в смысл для читательницы. Факты только из PROFILE.md.
- **Экспертный** — одна мысль, раскрытая до дна: боль читательницы, механика «почему так», что с этим делать. Без воды и без лекции.
- **Подборка** — список с человеческими комментариями, где каждая позиция — маленькая история или конкретный совет, а не пункт каталога.

Если тип не назван — выбери по теме и скажи одной строкой, какой выбрал.

## Структура и объём

Первая строка цепляет без кликбейта: узнавание, неожиданный факт или живая сцена. Дальше текст течёт по WRITING-RULES.md, 1500–2500 знаков, абзацы по 2–4 строки с воздухом. Финал — не резюме, а мысль, с которой хочется посидеть, или лёгкий мостик к продукту Валентина (не в каждом посте, примерно в одном из трёх).

## Проверка

Похоже на TOV-SAMPLES.md по ритму? Нет запрещённых конструкций? Нет выдуманных фактов? Тогда отдавай.
