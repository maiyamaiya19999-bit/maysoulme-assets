# Рабочее место Софья — установка и скиллы

Этот пакет настраивает Claude Code под тебя: он будет знать твою историю, метод, продукты и голос — и писать тексты, которые звучат как ты, а не как нейросеть.

## Как установить

1. Установи Claude по гайду Майи (ссылка на странице гайда).
2. Открой Claude Code и скажи ему одну фразу:

> Скачай архив https://maiyamaiya19999-bit.github.io/maysoulme-assets/sofya-guide/downloads/sofya-guide-full-package.zip и распакуй его в папку ~/sofya-guide-setup. Открой в ней файл INSTALL-FOR-CLAUDE.md и выполни установку строго по нему. Потом отчитайся по каждому пункту.

3. После установки первым делом вызови `/raspakovka` — Claude задаст вопросы и заполнит пробелы в твоём профиле. Чем подробнее ответишь, тем точнее будут все тексты.

## Скиллы

| Скилл | Что делает |
|---|---|
| `/raspakovka` | Задаёт вопросы по одному и заполняет твой профиль — с него начинаем |
| `/voice-edit` | Переписывает любой текст твоим живым голосом |
| `/tg-posts` | Посты для Telegram: личный, экспертный, подборка |
| `/reels-expert` | Сценарий экспертного reels под суфлёр |
| `/reels-story` | Сценарий reels с твоей личной историей |
| `/stories` | Серия из 6–8 сторис по теме |
| `/progrev` | Прогрев к запуску: план по дням с черновиками |
| `/selling-lesson` | Продающий урок по структуре Майи, 9 блоков |
| `/dozhim` | Цепочка дожимных сообщений для бота |
| `/offer` | Оффер и текст лендинга продукта |
| `/ca` | Анализ аудитории: аватар, боли, возражения |
| `/content-plan` | Контент-план на неделю под 15 минут в день |

## Правила, зашитые во все скиллы

Каждый скилл сначала читает твой профиль (`~/.claude/brand/PROFILE.md`), твои тексты (`TOV-SAMPLES.md`) и правила живой речи (`WRITING-RULES.md`). Ничего не выдумывает: нет факта — появится пометка `[нужна деталь]` и один вопрос тебе.

Если что-то сломалось или пишет не твоим голосом — напиши Майе.
