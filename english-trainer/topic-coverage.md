# Topic Coverage Map

Главная идея: естественные разговоры двух взрослых людей, которые познакомились, общаются и постепенно узнают друг друга. Путь: знакомство → переписка → small talk → юмор → интересы → работа → путешествия → друзья → семья → характер → образ жизни → свидания → прошлый опыт → отношения → ценности → планы → будущее.

Не только романтические сообщения. Никаких школьных «The green pencil is under the table».

## Словарь topicTags (только эти значения)

`acquaintance`, `texting`, `small-talk`, `humor`, `dating`, `relationships`, `past-relationships`, `feelings`, `family`, `work`, `travel`, `daily-life`, `food`, `friends`, `interests`, `deep-talk`, `plans`, `lifestyle`, `communication`

## Функции общения (внутри communication, минимумы)

согласиться — 20, не согласиться — 20, уточнить/переспросить — 30, отказаться вежливо — 15, предложить — 25, попросить — 25, удивиться — 15, пошутить — учтено в humor, выразить сомнение — 15, сменить тему — 10.

## Распределение по уровням

Каждая тема встречается на разных уровнях: знакомство и переписка гуще в A1–B1, отношения/ценности/глубокие разговоры гуще в B1–B2, но и в A2 есть простые дейтинг-фразы, и в B2 есть повседневная переписка.

## Правила уникальности

- Повторение грамматики — обязательно, повторение содержания — нельзя.
- Запрещено добивать количество шаблоном с заменой одного слова (Италия → Испания → Франция).
- Каждому пакету генерации выдаётся свой набор конкретных сценариев (например: «переписка перед первым звонком», «обсуждение пересадки в аэропорту», «разговор о ревности»), чтобы пакеты не пересекались по содержанию.

## Учёт

Validation-скрипт печатает счётчики topicTags; сверять после каждого пакета, дефициты закрывать в следующих.
