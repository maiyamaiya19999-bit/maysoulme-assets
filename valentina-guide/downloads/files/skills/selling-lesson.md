# Продающий урок

## 0. Перед началом

1. Прочитай `~/.claude/brand/PROFILE.md` — кто Валентина, её метод, история, продукты, аудитория, границы. Без этого не работай.
2. Прочитай `~/.claude/brand/TOV-SAMPLES.md` — её живые тексты, эталон голоса. Если файл почти пуст — пиши нейтрально-тепло и попроси Валентина прислать 10–15 её текстов.
3. Прочитай `~/.claude/brand/WRITING-RULES.md` — правила живой речи. Они обязательны для каждого текста.
4. Ничего не выдумывай: ни фактов, ни цифр, ни кейсов, ни регалий. Нет детали — ставь `[нужна деталь: какая]` прямо в тексте и задай Валентина один точный вопрос после ответа.
5. Готовый текст отдавай без вступлений «вот твой текст» и без разбора после — разбор только по просьбе.

## Перед началом — обязательные вопросы

Если этого нет в PROFILE.md, спроси и дождись ответов: точка А зрительницы, точка Б (что обещаем), продукт и наполнение, цена и полная цена, кейсы с разрешением публиковать. Без точки А и точки Б урок не пишется.

## Структура (9 блоков, тайминг ~20 минут)

1. **Остановить внимание (0:00–2:00).** Волшебная таблетка сразу: результат + срок + «даже если». Затем доказательство: живой кейс с цифрами или демонстрация на экране. Пообещай в конце цену, которой больше не будет.
2. **Доказать (2:00–4:00).** Почему Валентина можно верить: опыт, кейсы, регалии — между делом, без хвастовства.
3. **Моя история (4:00–7:00).** Путь Валентина из точки А аудитории: боль, поиск, находка. Только реальные факты.
4. **Где ты ошибаешься (7:00–10:00).** Три ошибки аудитории, из-за которых у неё не получилось. Каждая снимает вину: «ты не ленивая, тебя так научили».
5. **Что происходит на самом деле (10:00–13:00).** Система Валентина по шагам, просто и наглядно. Здесь же расчёт выгоды или потенциала цифрами («давай посчитаем вместе»), если продукт про деньги или экономию.
6. **Продукт (13:00–16:00).** Программа по модулям через результат каждого, наполнение, формат.
7. **Цена (16:00–17:30).** Цена + почему такая (из плюса: «чтобы могла позволить каждая», без «собираю отзывы» и без обесценивания). Полная цена перечёркнута, «дальше только выше», всё будущее — бесплатно тем, кто внутри.
8. **Страхи (17:30–19:30).** Четыре-пять реальных возражений аудитории и честные ответы. Гарантия, если Валентина готова её дать (спроси).
9. **Призыв (19:30–20:30).** Из плюса, без давления: картинка жизни после, ссылка под видео, «увидимся внутри».

## Правила

Чистая устная речь по WRITING-RULES.md — текст читается с суфлёра. Ремарки «(на экране — …)» отдельными строками. Кейсы и цифры только реальные; мест для скринов Валентина — ремарками.
